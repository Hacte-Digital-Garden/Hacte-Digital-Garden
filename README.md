# ✦ HacTe Digital Garden

## What is this?

A digital garden is a living collection of notes, ideas, and links. Unlike a blog, notes here are in various stages of completeness and grow over time.

Learn more about digital gardens here: https://maggieappleton.com/garden-history

---

## How to update the garden

You don't need to know how to code to contribute notes. All notes are written in **Markdown**, a simple formatting language. Here's how to get started:

### 1 - Learn the basics of Markdown

Markdown uses plain text with a few simple symbols to add formatting. For example, `# Title` makes a heading, `**bold**` makes text bold, and `[link text](url)` creates a link.

→ [Markdown Cheat Sheet](https://www.markdownguide.org/cheat-sheet/)

**Tags**
Add `#word` anywhere in a note to tag it. Tags help organize notes by topic and make them easier to find. For example, writing `#error` or `#incertesa` in the body of a note will tag that note accordingly.

**Linking notes**
To link one note to another, write the note's path, then "|", and then the notes name inside double brackets: `[[AION/esferes/error/error|Error]]`. When a note is linked to another, it will appear as a connected node in the **interactive graph**.

### 2 - Edit directly on GitHub

All the notes that have been published live in this GitHub repository as `.md` files. You can edit them directly in your browser — no software needed.

**Step 1 — Find the file.** Go to the repository's main page. You'll see a list of folders and files. Notes are stored inside the `src/site/notes/` folder. Click into it and browse until you find the note you want to edit.

**Step 2 — Open the editor.** Click on the file name to open it. Then click the **pencil icon** (✏️) in the top right corner of the file preview. This opens the file in an editor right in your browser.

**Step 3 — Make your changes.** Edit the text using Markdown. Be careful not to remove the frontmatter block at the top (the part between `---` lines). This is essencial to stay as is for the website to work properly.

**Step 4 — Save your changes.** When you're done, scroll to the bottom of the page and click the green **Commit changes** button. You can leave a short note describing what you changed.

The site will automatically rebuild and your changes will go live within a couple of minutes.
